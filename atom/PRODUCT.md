# ATOM product context

ATOM is a personal macOS AI workspace for chat, project work and computer tasks. Its native window brings together chats, a Board of agents and tasks, a Home/Dashboard, schedules, personal knowledge, plugins and settings. The user can select a provider/model, resume saved conversations and review the results of agent work.

The primary user is the owner of the Mac. Everyday actions should remain straightforward: resume a chat, give a project task, inspect a result and handle a decision. Optional technical details belong behind clear controls. Saved history, drafts and permissions must remain continuous across navigation and recovery.

Agents have editable instructions and roles, with capabilities checked by the host. Availability is separate from task state: Ready permits new work; Paused prevents new starts while already-running tasks retain their normal Stop and review controls. User instructions about permissions and Git handoff remain authoritative.

This file records product context from the implemented app and the owner's requests. It does not assert release readiness, benchmark superiority or complete parity with external projects. Current task-specific visual direction and verification are in [Board and Dashboard](docs/board-dashboard-design.md); native theme values live in `Theme.swift` and existing design documentation.
