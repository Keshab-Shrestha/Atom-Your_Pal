Wisp, the character

A pear-shaped ghost in matte mint-white. A cool inner shade pools at the hem, so it reads as a soft object, not a sticker. The face uses only eyes and a mouth: no cheeks, no props, no clip-art symbols. Moods come from pose, squash and the face.

Header portraits: a 96 pt head crop, re-posed per state.

Rationale

Settings structure

  • AI model lives on the main page: a 3-way provider control and one model popup replace 13 chips.
  • Five rows drill into sub-pages. Each row previews its current value. Dictation shares a page with Shortcuts, so both entries open the same sub-page.
  • One control per setting. Switches for on/off. Segmented controls for up to 4 short options. Popups for longer lists. A stepped slider where order matters (Movement).
  • Quit ZENO sits in the footer, away from the switches.
